
# Foodie - Food Delivery Website 🍔

A static food delivery website built using HTML and CSS as part of my frontend development learning journey.

## About the Project
Foodie is a food delivery website interface inspired by popular food platforms. It presents food categories, restaurant cards, a search section, and a footer.

## Features
- Navigation bar
- Food category section
- Restaurant cards with ratings and prices
- Location and restaurant search interface
- App promotion section
- Footer with company and social links
- Responsive styling for different screen sizes

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media queries

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Explore the Foodie website interface.

## What I Learned
- Structuring webpages with HTML
- Styling layouts using CSS
- Creating restaurant cards and navigation sections
- Using hover effects and responsive CSS
